# Plex Tracker

A tool to connect to your Plex watchlist, and list all titles in grouped lists:
* latest season finished airing
* latest season airing
* latest season not yet aired
* recently ended
* type groups: movies, tv shows, anime, anime movies

For each title show the following:
*  title
*  season number, 
*  latest episode air date date, 
*  (possibly) the poster image.

Also should support the following features:
* light / dark / system theme support
* floating controls for filter, sort, and group
* responsive design that looks beautiful for mobile, tablet and desktop
